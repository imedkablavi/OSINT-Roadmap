# OSINT Glossary — English

A concise reference for terms used throughout this repository.

| Term | Meaning |
| --- | --- |
| OSINT | Open Source Intelligence: intelligence produced from publicly available information through collection, verification, analysis, and reporting. |
| SOCMINT | Social Media Intelligence derived from publicly accessible social-platform activity. |
| GEOINT | Geospatial Intelligence: analysis of location, terrain, maps, imagery, and spatial relationships. |
| IMINT | Imagery Intelligence: information derived from images and video. |
| WEBINT | Intelligence derived from websites, web infrastructure, archives, and related public web sources. |
| CTI | Cyber Threat Intelligence: evidence-based intelligence about cyber threats, infrastructure, behaviors, campaigns, and risk. |
| PIR | Priority Intelligence Requirement: a clearly stated question that collection and analysis should answer. |
| Indicator | A data point that may be relevant but is not necessarily proof by itself. |
| Evidence | Information that directly supports or contradicts a claim and whose provenance can be explained. |
| Provenance | Where information came from, how it was obtained, and how it changed over time. |
| Primary source | A source directly connected to the event, record, statement, or artifact being examined. |
| Secondary source | A source that interprets, summarizes, or reports information originating elsewhere. |
| Corroboration | Independent evidence supporting the same claim. |
| Triangulation | Testing a conclusion using multiple sources, source types, or methods. |
| Attribution | Assessing whether an activity, account, artifact, or entity can reasonably be linked to a specific actor or owner. |
| Confidence level | A calibrated statement describing how strongly available evidence supports a judgment. |
| Collection gap | Information needed to answer a question that has not yet been obtained. |
| Pivot | Moving from one known entity or clue to a related public source or identifier. |
| Seed | The starting identifier or clue used for an investigation. |
| False positive | A result that appears relevant but is not actually connected to the subject or claim. |
| Confirmation bias | The tendency to seek or favor evidence that supports an existing belief while discounting contradictions. |
| Alternative hypothesis | A plausible competing explanation that should be tested against the evidence. |
| Timeline normalization | Converting dates and times into a common format/timezone so events can be compared accurately. |
| Chronolocation | Estimating or verifying when an image or event occurred using visual, environmental, archival, or temporal clues. |
| Geolocation | Estimating or verifying where an image, video, event, or object was located. |
| Reverse image search | Searching the web using an image to find visually related copies, earlier appearances, or context. |
| Metadata | Data about a file or record, such as creation time, software, camera information, or author fields. |
| EXIF | A common metadata format used by images; it may contain camera, timestamp, or location data when preserved. |
| WHOIS/RDAP | Public registration protocols and records used to inspect domain registration information where available. |
| DNS | Domain Name System: records linking domain names to services and infrastructure. |
| Certificate Transparency | Public logs of TLS certificates that can reveal historical or related hostnames. |
| Passive DNS | Historical or observed DNS data collected by third parties without actively probing the target. |
| OPSEC | Operational Security: practices that reduce unnecessary exposure of the researcher, methods, or investigation. |
| Source dependency | A situation where apparently separate sources ultimately rely on the same original source. |
| Stop condition | A predefined point where collection should end because the question is answered, evidence is sufficient, or further activity would exceed scope. |
| Evidence ladder | A structured way to rank evidence by directness, independence, reliability, and relevance. |
| Link analysis | Mapping explicitly defined relationships among entities, sources, events, or infrastructure. |
| Entity resolution | Determining which real-world organization, person, account, or record a name or identifier refers to. |
| Digital footprint | Public traces associated with an entity across websites, accounts, documents, domains, and archives. |
| Dark web awareness | Understanding references to dark-web ecosystems without engaging in unauthorized access or illegal activity. |
| Public record | A government, corporate, legal, regulatory, or institutional record lawfully available to the public. |
| Source log | A structured list of sources with URLs, dates, timestamps, notes, and relevance. |
| Intelligence note | A short report that answers a defined question with key judgments, supporting evidence, confidence, and limitations. |
