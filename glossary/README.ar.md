# قاموس OSINT - العربية

مرجع مختصر للمصطلحات المستخدمة في المشروع.

| المصطلح | المعنى |
| --- | --- |
| OSINT | الاستخبارات مفتوحة المصدر: استخبارات تُبنى من معلومات متاحة للعامة عبر الجمع والتحقق والتحليل والتقرير. |
| SOCMINT | استخبارات وسائل التواصل الاجتماعي المبنية على النشاط العام في المنصات الاجتماعية. |
| GEOINT | الاستخبارات الجغرافية المكانية: تحليل المواقع والخرائط والتضاريس والصور والعلاقات المكانية. |
| IMINT | استخبارات الصور: المعلومات المستخرجة من الصور والفيديو. |
| WEBINT | استخبارات تعتمد على المواقع، البنية العامة للويب، الأرشيفات، والمصادر المفتوحة المرتبطة بها. |
| CTI | استخبارات التهديدات السيبرانية: استخبارات قائمة على الأدلة حول التهديدات والبنية التحتية والسلوكيات والحملات والمخاطر. |
| PIR | متطلب استخباراتي ذو أولوية: سؤال واضح يجب أن تجيب عنه عملية الجمع والتحليل. |
| Indicator | مؤشر قد يكون ذا صلة لكنه لا يُعد دليلاً كافياً بمفرده. |
| Evidence | معلومة تدعم أو تناقض ادعاءً بشكل مباشر ويمكن شرح مصدرها وسياقها. |
| Provenance | أصل المعلومة: من أين أتت وكيف جُمعت وكيف تغيّرت عبر الزمن. |
| Primary Source | مصدر أولي مرتبط مباشرة بالحدث أو السجل أو التصريح أو المادة قيد الفحص. |
| Secondary Source | مصدر ثانوي يفسر أو يلخص أو ينقل معلومات مصدرها مكان آخر. |
| Corroboration | دعم الادعاء بأدلة مستقلة إضافية. |
| Triangulation | اختبار الاستنتاج باستخدام عدة مصادر أو أنواع مصادر أو طرق مختلفة. |
| Attribution | تقييم مدى إمكانية ربط نشاط أو حساب أو مادة أو كيان بجهة أو مالك محدد. |
| Confidence Level | مستوى الثقة: وصف معاير لقوة دعم الأدلة للحكم النهائي. |
| Collection Gap | فجوة جمع: معلومة نحتاجها للإجابة عن السؤال لكنها غير متوفرة بعد. |
| Pivot | الانتقال من معلومة أو كيان معروف إلى مصدر أو معرف عام مرتبط به. |
| Seed | نقطة البداية في التحقيق، مثل اسم مستخدم أو نطاق أو صورة أو شركة. |
| False Positive | نتيجة تبدو ذات صلة لكنها في الواقع غير مرتبطة بالموضوع أو الادعاء. |
| Confirmation Bias | تحيز التأكيد: الميل للبحث عن الأدلة التي تؤيد الفكرة المسبقة وتجاهل ما يناقضها. |
| Alternative Hypothesis | فرضية بديلة: تفسير منطقي منافس يجب اختباره ضد الأدلة. |
| Timeline Normalization | توحيد التواريخ والأوقات ضمن تنسيق ومنطقة زمنية مشتركة للمقارنة الدقيقة. |
| Chronolocation | التحقق أو التقدير الزمني لصورة أو حدث اعتماداً على قرائن بصرية أو بيئية أو أرشيفية أو زمنية. |
| Geolocation | تحديد أو التحقق من الموقع الجغرافي لصورة أو فيديو أو حدث أو عنصر. |
| Reverse Image Search | البحث العكسي بالصورة للعثور على نسخ مشابهة أو ظهور أقدم أو سياق إضافي. |
| Metadata | بيانات تصف ملفاً أو سجلاً، مثل وقت الإنشاء أو البرنامج أو معلومات الكاميرا أو المؤلف. |
| EXIF | تنسيق بيانات وصفية شائع في الصور، وقد يحتوي على معلومات الكاميرا أو الوقت أو الموقع إن بقي محفوظاً. |
| WHOIS/RDAP | بروتوكولات وسجلات عامة لفحص بيانات تسجيل النطاقات حيث تكون متاحة. |
| DNS | نظام أسماء النطاقات: سجلات تربط أسماء النطاقات بالخدمات والبنية التحتية. |
| Certificate Transparency | سجلات عامة لشهادات TLS يمكن أن تكشف أسماء نطاقات فرعية أو تاريخية مرتبطة. |
| Passive DNS | بيانات DNS تاريخية أو مرصودة تجمعها جهات خارجية دون فحص نشط للهدف. |
| OPSEC | الأمن التشغيلي: ممارسات تقلل كشف الباحث أو طرقه أو تفاصيل التحقيق بلا داعٍ. |
| Source Dependency | اعتماد المصادر: عندما تبدو عدة مصادر مستقلة لكنها تعتمد في الأصل على نفس المصدر. |
| Stop Condition | شرط توقف محدد مسبقاً ينهي الجمع عندما يُجاب عن السؤال أو تكفي الأدلة أو يتجاوز العمل النطاق. |
| Evidence Ladder | سلم الأدلة: طريقة لترتيب قوة الأدلة حسب المباشرة والاستقلالية والموثوقية والصلة. |
| Link Analysis | تحليل الروابط بين الكيانات أو المصادر أو الأحداث أو البنى التحتية بعلاقات معرفة بدقة. |
| Entity Resolution | تحديد أي كيان حقيقي يشير إليه اسم أو معرف أو سجل معين. |
| Digital Footprint | البصمة الرقمية: الآثار العامة المرتبطة بكيان عبر المواقع والحسابات والمستندات والنطاقات والأرشيفات. |
| Dark Web Awareness | فهم بيئة ومراجع الويب المظلم دون وصول غير مصرح به أو نشاط غير قانوني. |
| Public Record | سجل حكومي أو قانوني أو تجاري أو تنظيمي متاح للعامة بشكل قانوني. |
| Source Log | سجل مصادر منظم يتضمن الروابط والتواريخ والتوقيت والملاحظات والصلة. |
| Intelligence Note | مذكرة استخباراتية قصيرة تجيب عن سؤال محدد وتعرض الأحكام الرئيسية والأدلة والثقة والقيود. |
