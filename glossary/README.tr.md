# OSINT Sözlüğü — Türkçe

Projede kullanılan temel terimler için kısa başvuru kaynağı.

| Terim | Anlamı |
| --- | --- |
| OSINT | Açık Kaynak İstihbaratı: kamuya açık bilgilerden toplama, doğrulama, analiz ve raporlama yoluyla üretilen istihbarat. |
| SOCMINT | Kamuya açık sosyal medya faaliyetlerinden elde edilen sosyal medya istihbaratı. |
| GEOINT | Mekânsal İstihbarat: konum, harita, arazi, görüntü ve mekânsal ilişkilerin analizi. |
| IMINT | Görüntü İstihbaratı: fotoğraf ve videolardan elde edilen bilgi. |
| WEBINT | Web siteleri, web altyapısı, arşivler ve ilişkili açık web kaynaklarından elde edilen istihbarat. |
| CTI | Siber Tehdit İstihbaratı: tehditler, altyapı, davranışlar, kampanyalar ve risk hakkında kanıta dayalı istihbarat. |
| PIR | Öncelikli İstihbarat Gereksinimi: toplama ve analizin yanıtlaması gereken açık soru. |
| Indicator | Tek başına kanıt olmayan ancak ilgili olabilecek gösterge. |
| Evidence | Bir iddiayı doğrudan destekleyen veya çürüten ve kaynağı açıklanabilen bilgi. |
| Provenance | Bilginin nereden geldiği, nasıl elde edildiği ve zaman içinde nasıl değiştiği. |
| Primary Source | İncelenen olay, kayıt, açıklama veya artefaktla doğrudan bağlantılı birincil kaynak. |
| Secondary Source | Başka bir kaynaktan gelen bilgiyi yorumlayan, özetleyen veya aktaran ikincil kaynak. |
| Corroboration | Aynı iddiayı bağımsız ek kanıtlarla destekleme. |
| Triangulation | Bir sonucu birden fazla kaynak, kaynak türü veya yöntemle test etme. |
| Attribution | Bir faaliyet, hesap, artefakt veya varlığın belirli bir aktör ya da sahibine bağlanabilirliğini değerlendirme. |
| Confidence Level | Mevcut kanıtın bir yargıyı ne kadar güçlü desteklediğini ifade eden güven düzeyi. |
| Collection Gap | Soruyu yanıtlamak için gereken ancak henüz elde edilmemiş bilgi. |
| Pivot | Bilinen bir ipucundan ilişkili açık kaynağa veya tanımlayıcıya geçiş. |
| Seed | Araştırmanın başlangıç ipucu: kullanıcı adı, alan adı, görsel, şirket vb. |
| False Positive | İlgili görünen ancak gerçekte konu veya iddiayla bağlantılı olmayan sonuç. |
| Confirmation Bias | Mevcut görüşü destekleyen kanıtı arama, çelişen kanıtı küçümseme eğilimi. |
| Alternative Hypothesis | Kanıta karşı test edilmesi gereken makul alternatif açıklama. |
| Timeline Normalization | Olayları doğru karşılaştırmak için tarih/saatleri ortak biçim ve saat dilimine dönüştürme. |
| Chronolocation | Görsel veya olayın zamanını görsel, çevresel, arşivsel veya zamansal ipuçlarıyla tahmin/doğrulama. |
| Geolocation | Görsel, video, olay veya nesnenin yerini tahmin/doğrulama. |
| Reverse Image Search | Görsel kullanarak benzer kopyaları, erken yayınları veya bağlamı web'de arama. |
| Metadata | Bir dosya veya kayıt hakkındaki oluşturulma zamanı, yazılım, kamera veya yazar gibi veriler. |
| EXIF | Görsellerde bulunabilen kamera, zaman veya konum gibi metadata formatı. |
| WHOIS/RDAP | Alan adı kayıt bilgilerini mevcut olduğu ölçüde incelemek için kullanılan açık kayıt/protokoller. |
| DNS | Alan adlarını hizmet ve altyapıyla ilişkilendiren Domain Name System kayıtları. |
| Certificate Transparency | TLS sertifikalarının halka açık günlükleri; tarihsel veya ilişkili host adlarını ortaya çıkarabilir. |
| Passive DNS | Hedefi aktif olarak taramadan üçüncü taraflarca toplanmış tarihsel veya gözlemlenmiş DNS verisi. |
| OPSEC | Operasyonel Güvenlik: araştırmacının, yöntemlerin veya araştırmanın gereksiz ifşasını azaltan uygulamalar. |
| Source Dependency | Ayrı görünen kaynakların aslında aynı orijinal kaynağa dayanması durumu. |
| Stop Condition | Soru yanıtlandığında, kanıt yeterli olduğunda veya sonraki adım kapsamı aştığında araştırmayı bitirme kuralı. |
| Evidence Ladder | Kanıtları doğrudanlık, bağımsızlık, güvenilirlik ve ilgililik bakımından sıralama yöntemi. |
| Link Analysis | Varlıklar, kaynaklar, olaylar veya altyapı arasındaki açıkça tanımlanmış ilişkileri haritalama. |
| Entity Resolution | Bir isim ya da tanımlayıcının hangi gerçek kişi, kurum, hesap veya kayda karşılık geldiğini belirleme. |
| Digital Footprint | Bir varlığın web siteleri, hesaplar, belgeler, alan adları ve arşivlerdeki kamuya açık izleri. |
| Dark Web Awareness | Yetkisiz erişim veya yasa dışı faaliyete girmeden dark web ekosistemleri hakkında farkındalık. |
| Public Record | Kamuya yasal olarak açık devlet, şirket, hukuk, düzenleyici veya kurumsal kayıt. |
| Source Log | URL, tarih, zaman, not ve ilgililik bilgisi içeren düzenli kaynak kaydı. |
| Intelligence Note | Belirli bir soruya temel yargılar, kanıt, güven ve sınırlamalarla yanıt veren kısa istihbarat notu. |
