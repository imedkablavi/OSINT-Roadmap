# OSINT Roadmap Updates

This directory is the project's **return-visit layer**: short, dated notes about meaningful changes to tools, learning material and investigation workflows.

The goal is not to publish filler on a schedule. An update is worth publishing when something changed that affects how a researcher should work.

## Update types

- **Tool Radar** — new, changed, replaced, deprecated or newly reviewed tools.
- **Method Update** — a workflow or verification method changed.
- **New Lab** — a practice exercise was added or substantially revised.
- **Dataset Update** — a useful public dataset changed or expanded.
- **Language Update** — Arabic or Turkish material reached parity with an English section.

## Editorial rule

Every update should answer at least one of these:

1. What changed?
2. Why does it matter to an investigator?
3. What should the reader do differently now?
4. What source confirms the change?

If an update cannot answer one of those questions, it probably does not deserve a separate post.
