# أدوات OSINT مفتوحة المصدر الموثقة

> آخر مراجعة: **2026-08-24** · العربية · [English](open-source-tools.md) · [Türkçe](open-source-tools.tr.md)

تضم هذه الصفحة أدوات مفتوحة المصدر تم التحقق من المشروع الأصلي والترخيص والدور العملي الحالي لكل أداة قبل إضافتها. كون الأداة مفتوحة المصدر لا يلغي متطلبات التفويض أو الخصوصية أو شروط مزودي البيانات أو قواعد حفظ البيانات.

| الأداة | الترخيص | المدخلات | الأفضل من أجل | أهم قيد |
| --- | --- | --- | --- | --- |
| [theHarvester](https://github.com/laramies/theHarvester) | GPL-2.0 | نطاق، مؤسسة | تجميع نتائج من مصادر عامة سلبية لاكتشاف النطاقات والمضيفين والعلاقات المرتبطة | المصادر والحصص ومتطلبات مفاتيح API تتغير، وبعض الخيارات تضيف نشاطًا شبكيًا |
| [OWASP Amass](https://github.com/owasp-amass/amass) | Apache-2.0 | نطاق، مؤسسة، ASN | اكتشاف الأصول الخارجية ورسم سطح الهجوم | التقنيات النشطة يجب استخدامها فقط ضمن أصول تملكها أو لديك تفويض صريح لاختبارها |
| [Subfinder](https://github.com/projectdiscovery/subfinder) | MIT | نطاق | تعداد النطاقات الفرعية عبر مصادر سلبية مدعومة | عدد من المصادر المفيدة يحتاج مفاتيح API وقد تتغير المصادر الخارجية أو تتوقف |

| [MISP](https://github.com/MISP/MISP) | AGPL-3.0 | IOC، حدث، مؤسسة | مشاركة معلومات التهديدات والأحداث والمؤشرات بصيغة منظمة | جودة بيانات المجتمع متفاوتة وتحتاج قواعد واضحة للمشاركة والبيانات الحساسة |

## متى تستخدم كل أداة؟

- **theHarvester:** عندما تريد تجميع استعلامات عدة مصادر عامة ضمن مسار قابل لإعادة التنفيذ بدل فتح كل مزود يدويًا.
- **OWASP Amass:** عندما تحتاج اكتشافًا أعمق للأصول الخارجية مع فصل واضح بين العمل السلبي والنشط.
- **Subfinder:** عندما تحتاج أداة مركزة وخفيفة لتعداد النطاقات الفرعية بشكل سلبي.
- **OpenCTI Community Edition:** عندما تصبح المشكلة تنظيم المعرفة والعلاقات والمصادر ومستويات الثقة، لا مجرد جمع IOC إضافي.
- **MISP:** عندما تحتاج تبادلًا منظمًا لمعلومات التهديدات مع فريق أو مجتمع موثوق.

## قاعدة الاستخدام الآمن

كون الهدف متاحًا للعامة لا يعني أن لديك تفويضًا لفحصه. حتى المصادر السلبية تستقبل كلمات البحث وقد تسجلها وتفرض شروطًا وحصصًا. أي DNS resolution أو probing أو scanning أو تحقق نشط يجب أن يقتصر على نطاق تملكه أو تملك تفويضًا صريحًا للعمل عليه.

نتيجة الأداة هي **إشارة أو ملاحظة** وليست إثباتًا تلقائيًا. سجّل المصدر والوقت والاستعلام ومستوى الثقة والقيود المهمة قبل إدخال النتيجة في تقرير.
