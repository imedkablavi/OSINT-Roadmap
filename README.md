## What makes this roadmap different?

The repository is built around a simple idea:

```text
Finding information is discovery.
Proving what it means is investigation.
```

Instead of only collecting tool names, the project teaches:

- how to frame a research question;
- how to trace information back to its original source;
- how to distinguish independent confirmation from copied reporting;
- how to verify images, timelines, domains, public records, and open social content;
- how to test alternative explanations instead of confirming the first theory;
- how to document sources, confidence, and limitations;
- how to use AI as a research assistant without treating model output as evidence;
- how to practice with safe labs and reusable report templates.

## Core learning path

```text
Foundations
    ↓
Search & Discovery
    ↓
Source Verification
    ↓
Visual / GEOINT / SOCMINT / WEBINT
    ↓
Timeline & Relationship Analysis
    ↓
Alternative Hypothesis Testing
    ↓
Reporting & Confidence Assessment
    ↓
Specialization
```

## Safe practice first

The labs are designed around public, permissioned, or purpose-built material. The project does not teach unauthorized access, credential attacks, deceptive social engineering, stalking, harassment, doxxing, or bypassing access controls.

```text
If the next step requires intrusion, deception, private access,
or bypassing a security restriction, stop.
```
