## Bu merkezi nasıl kullanmalısın?

Her şeyi bir defada okumak yerine tek bir beceri seç ve küçük bir artifact üret:

| Beceri | Örnek çıktı |
| --- | --- |
| Kaynak doğrulama | kaynak tablosu + confidence kararı |
| Görsel | kısa visual verification raporu |
| Domain | passive footprint |
| Şirket | public registry tabanlı entity profile |
| Timeline | timezone-normalized olay tablosu |
| CTI | kısa intelligence note |

Amaç araç isimlerini ezberlemek değil; **kaynağı neden kullandığını, çıktının neyi desteklediğini ve sonucun sınırlarını** açıklayabilmektir.
