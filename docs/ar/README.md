## ابدأ من هنا

```text
خارطة الطريق العربية
        ↓
منهجيات البحث
        ↓

        ↓

        ↓
المختبرات العملية
        ↓
GEOINT والتخصصات
        ↓
التقرير + Portfolio
```

## كيف تستخدم المركز؟

لا تقرأ كل شيء دفعة واحدة. اختر سؤالاً أو مهارة، ثم أنتج artifact صغيراً:

| المهارة | مخرج مناسب |
| --- | --- |
| التحقق من مصدر | جدول مصادر + حكم ثقة |
| صورة | تقرير تحقق بصري قصير |
| Domain | Passive footprint |
| شركة | Entity profile من سجلات عامة |
| Timeline | جدول موحد بالتوقيت |
| CTI | Intelligence note مختصر |

الهدف ليس حفظ أسماء الأدوات، بل أن تتمكن من شرح **لماذا استخدمت المصدر، ماذا يثبت، وما حدود الاستنتاج**.
