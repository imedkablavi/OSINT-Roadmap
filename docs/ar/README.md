## مكتبة أدوات OSINT بالعربية

**[افتح مكتبة الأدوات العربية →](../../tools/tool-library.ar.md)**

المكتبة الجديدة تغطي أكثر من 70 أداة ومصدر ضمن فئات واضحة:

- البحث والأرشفة
- Usernames والهوية العامة
- الصور والفيديو
- GEOINT والأقمار الصناعية
- Domains وIPs والبنية التحتية
- CTI وIOC enrichment
- الشركات والملكية والسجلات العامة
- الطيران والبحر
- المستندات والبيانات
- مساحات التحقيق وتحليل العلاقات
- Blockchain

كل أداة معها Input، الكلفة، المستوى، الاستخدام الأفضل، وأهم limitation.

إذا تم تفعيل GitHub Pages يمكنك أيضاً استخدام **Tool Finder** التفاعلي:

`https://imedkablavi.github.io/OSINT-Roadmap/tool-finder.html`

## كيف تستخدم المركز؟

لا تقرأ كل شيء دفعة واحدة. اختر سؤالاً أو مهارة، ثم أنتج artifact صغيراً:

| المهارة | مخرج مناسب |
| --- | --- |
| التحقق من مصدر | جدول مصادر + حكم ثقة |
| صورة | تقرير تحقق بصري قصير |
| Domain | Passive footprint |
| شركة | Entity profile من سجلات عامة |
| Timeline | جدول موحد بالتوقيت |
| CTI | Intelligence note مختصر |

الهدف ليس حفظ أسماء الأدوات، بل أن تتمكن من شرح **لماذا استخدمت المصدر، ماذا يثبت، وما حدود الاستنتاج**.
