# OSINT Skill Matrix & Progress Tracker

Use this matrix to measure what you can **demonstrate**, not what you have read.

## Levels

- **L0 - Unfamiliar:** cannot perform the task yet.
- **L1 - Guided:** can perform it with a checklist/tutorial.
- **L2 - Independent:** can perform it alone and document the method.
- **L3 - Defensible:** can explain limitations, challenge the result, and reproduce the work.
- **L4 - Mentor:** can review another researcher's work and identify methodological problems.

## Matrix

| Skill | L1 evidence | L2 evidence | L3 evidence |
| --- | --- | --- | --- |
| Research question | rewrite a broad task into a focused question | define scope + stop condition | design PIRs and collection plan |
| Search | use operators correctly | use multiple engines/languages | document search strategy and blind spots |
| Source verification | identify primary/secondary sources | trace provenance | expose source dependency and contradictions |
| Archives | retrieve historical page | build change timeline | distinguish archive timestamp from event time |
| Image verification | reverse-search image | find earliest public appearance | combine visual clues + independent context |
| GEOINT | recognize country-level clues | geolocate training image | challenge location with competing candidates |
| Chronolocation | identify temporal clues | test date/time consistency | combine archives, weather, shadows, construction, season |
| SOCMINT | collect public profile signals | compare candidate identities | produce calibrated attribution assessment |
| Digital footprint | find public traces | build evidence table | minimize privacy collection and challenge attribution |
| Domains/Web | inspect public records | build passive web timeline | distinguish shared infrastructure from meaningful linkage |
| Company research | resolve legal entity | reconstruct corporate timeline | audit ownership/sanctions claims against primary records |
| CTI | read a threat report critically | enrich public indicators passively | produce PIR-driven assessment with ATT&CK mapping |
| Timeline analysis | record events | normalize timezones | distinguish event/observed/published/archived times |
| Link analysis | draw labeled relationships | attach evidence to every edge | identify weak/shared/common relationships |
| Bias control | name confirmation bias | write alternative hypothesis | deliberately attack strongest conclusion |
| Reporting | write source-backed finding | state confidence + limitations | produce reproducible intelligence note |
| OPSEC & ethics | identify unsafe step | use stop conditions | review data minimization and researcher exposure |

## Promotion rule

Do not mark a skill complete because you watched a video or used a tool once.

A useful promotion standard is:

```text
L1: I followed the method.
L2: I reproduced it independently.
L3: I can defend the result and explain why it might be wrong.
L4: I can review someone else's work and improve it.
```

## Suggested portfolio

A strong beginner-to-intermediate portfolio can contain:

- 2 claim-verification reports;
- 2 archive reconstruction exercises;
- 2 image verification exercises;
- 2 GEOINT challenges;
- 1 digital-footprint attribution assessment;
- 1 company investigation profile;
- 1 CTI intelligence note;
- 1 investigation where your first hypothesis turned out to be wrong.

The last one matters: good OSINT includes documented corrections, not only successful guesses.
