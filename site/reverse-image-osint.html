Verification sequence

Run complementary indexes

Use more than one visual-search engine because each index sees different copies and crops.

Find the earliest credible context

Compare dates, captions and publication chains. A popular repost is not necessarily the original source.

Inspect the file

Check metadata when available, but remember social platforms commonly remove it. Missing EXIF proves very little.

Cross-check the scene

Use landmarks, road geometry, weather, shadows, terrain and other visible details to test the claimed place and time.

Evidence rule: a visual match can show that images are related; it does not automatically prove who created the image, where it was taken, or whether the accompanying claim is true.
