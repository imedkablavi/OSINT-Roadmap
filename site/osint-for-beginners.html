A five-stage workflow

1. Frame the question

Write the claim or intelligence requirement before searching. Decide what would count as evidence and what would change your mind.

2. Discover

Use search engines, archives, public records and specialist indexes to find candidate sources. Discovery produces leads, not proof.

3. Verify

Trace claims to primary sources, compare independent sources, capture timestamps and distinguish original evidence from copied reporting.

4. Analyze

Build timelines, test alternative explanations and separate observed facts from inference and attribution.

5. Report

Record query, source, date, limitations and confidence so another researcher can reproduce the work.

What to practice first

Start with lawful public examples: verify a news image, compare archived versions of a webpage, resolve a public company entity, or document a domain's public registration and certificate history. Use the practice labs and report template.

Stop rule: if the next step requires intrusion, deception, private access or bypassing a security restriction, stop.
